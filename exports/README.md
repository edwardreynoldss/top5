# Exported Shorts

Finished ranking videos are saved under a folder per **upload channel**:

- `exports/animals/ranking-animals-1.mp4`
- `exports/animals/ranking-animals-1.2.mp4` (re-export of the same clip set)
- `exports/funny/ranking-funny-1.mp4`
- …

Use the **Channel** selector in the top bar (defaults: Animals, Funny). Add channels anytime — each gets its own folder.

Video numbers come from a per-channel counter (not by scanning this folder). **Reset** starts a new video number; exporting again without Reset adds a version suffix (`.2`, `.3`, …).
