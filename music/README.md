# Drop background music beds here

Put `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`, or `.webm` files in this folder.

They show up in the editor under **Look → Background music → Folder (music/)** — no per-clip upload needed.

The selected bed loops under the whole ranking video (preview + export) so silent clips still have atmosphere.

Tips:
- Prefer beds without loud vocals that fight clip audio
- Use clear names (`lofi-bed.mp3`, `nature-ambience.wav`)
- Click **Refresh** in Look after adding files
- Turn on **Auto-pick from folder** to grab a bed automatically when none is selected
