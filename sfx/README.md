# Drop sound effects here

Put `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`, or `.webm` files in this folder.

They show up in the editor under **SFX → Folder (sfx/)** — no manual upload needed.

Tips:
- Prefer short samples (under a few seconds)
- Use clear file names (`vine-boom.mp3`, `get-out.wav`)
- The site only reads a lightweight file list on load; audio streams when you preview or export
- Restart / refresh the SFX tab (or click Refresh) after adding files
